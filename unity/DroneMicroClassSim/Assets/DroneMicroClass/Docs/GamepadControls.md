# Gamepad Controls

默认布局面向 Xbox、PlayStation 和常见 XInput 兼容手柄。键盘映射与双摇杆保持一一对应。

## 飞行

| 遥控器操作 | 飞行功能 | 键盘映射 |
|---|---|---|
| 左摇杆 ↑ | 向前俯仰 | W |
| 左摇杆 ↓ | 向后俯仰 | S |
| 左摇杆 ← | 向左横滚 | A |
| 左摇杆 → | 向右横滚 | D |
| 右摇杆 ↑ | 上升 | ↑ |
| 右摇杆 ↓ | 下降 | ↓ |
| 右摇杆 ← | 向左偏航 | ← |
| 右摇杆 → | 向右偏航 | → |

## 安全操作

- 解锁/起飞：左摇杆右下 + 右摇杆左下，长按 2 秒
- 键盘解锁/起飞：`S + D + ↓ + ←`，长按 2 秒
- 锁定电机：左摇杆左下 + 右摇杆右下，长按 2 秒
- 键盘锁定：`S + A + ↓ + →`，长按 2 秒
- 降落：`B / Circle` 或 `L`
- 重置无人机：`Back + Start / Share + Options` 或 `Backspace`
- 左摇杆按下：切换定高
- 右摇杆按下：切换自稳

## 摄像机与调试

- `PageUp / PageDown`：调整云台俯仰
- `B`：云台回正
- `C / V`：切换飞行视角
- `F2`：打开或关闭手柄检测面板
