# Gamepad Controls

默认布局使用美国手（Mode 2），面向 FPV 飞行训练和 Liftoff 默认习惯。键盘映射与四个飞行动作保持一一对应。

## 4.1 基本控制

| 摇杆 | 功能 | 键盘映射 |
|---|---|---|
| 左摇杆上下 | 油门（Throttle）/ 升降 | ↑ / ↓ |
| 左摇杆左右 | 偏航（Yaw） | ← / → |
| 右摇杆上下 | 俯仰（Pitch） | W / S |
| 右摇杆左右 | 横滚（Roll） | A / D |

## 4.2 美国手 vs 日本手

### 美国手（Mode 2）

| 摇杆 | 功能 |
|---|---|
| 左摇杆 | 油门 + 偏航 |
| 右摇杆 | 俯仰 + 横滚 |

这是当前默认设置，适合大多数 FPV 飞手。

RadioMaster Pocket Joystick 当前按通道映射为：轴01=右摇杆左右/横滚，轴02=右摇杆上下/俯仰，轴03=左摇杆上下/油门，轴04=左摇杆左右/偏航。

### 日本手（Mode 1）

| 摇杆 | 功能 |
|---|---|
| 左摇杆 | 俯仰 + 偏航 |
| 右摇杆 | 油门 + 横滚 |

传统遥控器常用。需要切换时，在 `DroneController` 的 `Gamepad Stick Mode` 里选择 `Mode1Japanese`。

## 安全操作

- 解锁/起飞：左摇杆右下 + 右摇杆左下，长按 2 秒
- 锁定电机：左摇杆左下 + 右摇杆右下，长按 2 秒
- 键盘解锁/起飞：`S + D + ↓ + ←`，长按 2 秒
- 键盘锁定：`S + A + ↓ + →`，长按 2 秒
- 降落：`B / Circle` 或 `L`
- 重置无人机：`Back + Start / Share + Options` 或 `Backspace`
- 左摇杆按下：切换定高
- 右摇杆按下：切换自稳

## 摄像机与调试

- `PageUp / PageDown`：调整云台俯仰
- `B`：云台回正
- `C / V`：切换飞行视角
- `G`：直接切换到固定人高观察视角，也可用 `C / V` 循环切入。机位在起飞点后方约 8 米，离脚下地面 1.6 米，整次飞行保持位置固定，自动转向飞机。
- 人高视角在飞机距离超过 18 米后平滑增加焦距，最多放大 8 倍；飞机飞近时自动缩回。切回其他视角时恢复原来的视野。
- `F2`：打开或关闭手柄检测面板
